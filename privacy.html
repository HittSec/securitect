Privacy Policy for Securitect by HittSec

Effective Date: May 22, 2026

Overview

Securitect by HittSec is a browser extension designed to help security analysts clean, decode, extract, enrich, and format security data for SOC-ready workflows.

Data Processing

Securitect by HittSec processes all pasted reports, logs, indicators of compromise, decoded artifacts, custom templates, and generated reports locally in the user’s browser.

The extension does not transmit pasted content, logs, IOCs, decoded artifacts, reports, templates, or history to Securitect, HittSec, or any external server.

Local Storage

Securitect by HittSec uses browser extension storage to save user preferences and locally stored data, including:

  • Recent History
  • Current workspace state
  • Custom report templates
  • Selected template preferences

This data remains stored locally in the user’s browser and can be cleared by the user from within the extension.

Users can remove current workspace data using Clear All.

Users can remove saved history using Clear History.

Third-Party Threat Intelligence Links

Securitect by HittSec may generate clickable lookup links for third-party threat intelligence services such as VirusTotal, AbuseIPDB, GreyNoise, URLScan, and ANY.RUN.

These services are only opened when the user manually clicks a lookup link.

When a user clicks a third-party lookup link, the selected indicator may be included in the destination URL and shared with that third-party service according to that service’s own privacy policy.

Securitect by HittSec does not automatically submit indicators to third-party services.

Data Collection

Securitect by HittSec does not collect, sell, share, or transmit user data.

The extension does not use analytics, tracking pixels, telemetry, advertising identifiers, or remote logging.

Permissions

Securitect by HittSec requests permissions only to support its core functionality:

  • clipboardWrite
  • storage

clipboardWrite is used so users can copy cleaned output, decoded artifacts, IOCs, lookup links, and formatted reports to their clipboard.

storage is used to locally save recent history, workspace state, and custom templates.

Changes to This Policy

This privacy policy may be updated if Securitect by HittSec adds new functionality, such as API integrations, cloud sync, account features, analytics, or external processing.
